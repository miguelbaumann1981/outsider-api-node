# Outsider API RESTful Project

This pre-initialised project has everything you need to work with TypeScript, Express, and Rest.

Each step of its configuration has already been completed in the course, so all you need to do is clone the project and start working.

## Instalation

1. Clone .env.template to .env and configure environment variables
2. Execute `npm install` to install dependencies
3. In case you need to run a BBDD, configure docker-compose.yml and execute `docker compose up -d` to run the services
4. Execute `npm run dev` to run the project in development mode
